# Pesquisa de Opinião - TudoWeb

## Descrição

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião sobre o atendimento da empresa TudoWeb.

O programa coleta o nome, a idade e a opinião de 50 entrevistados. Cada participante pode avaliar o atendimento como:

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

O sistema utiliza estruturas de repetição, estruturas de decisão, funções e validação de dados. Ao final da pesquisa, são exibidas as quantidades de respostas classificadas como EXCELENTE e RUIM.

O projeto também foi testado com 10 entrevistados para verificar o funcionamento correto do programa.

## Tecnologias utilizadas

- Python
- Visual Studio Code
- GitHub

## Objetivo

Aplicar conceitos de programação estruturada, especialmente estruturas de repetição, decisão, funções e validação de entradas.
